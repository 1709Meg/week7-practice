# Java Exception Handling

A collection of Java exercises completed as part of my Advanced Programming course. This project focuses on identifying, catching, throwing, and handling exceptions in Java.

## Topics Covered

- `try` and `catch` blocks
- Multiple catch blocks
- Nested exception handling
- `finally` blocks
- `throw` and `throws`
- Custom exceptions
- Checked and unchecked exceptions
- Runtime exception handling

## Exception Types Practiced

- `ArithmeticException`
- `ArrayIndexOutOfBoundsException`
- `NumberFormatException`
- `StringIndexOutOfBoundsException`
- `NullPointerException`
- `IllegalArgumentException`
- `IOException`
- Custom exception classes

## Practice Programs

### CountLetters
Handles invalid characters while counting letter frequency in user input.

### ParseInts
Reads mixed text input and sums only valid integers.

### Factorials
Validates factorial input and throws exceptions for negative values or values that exceed the supported range.

### Additional Examples
Includes demonstrations of nested try-catch blocks, multiple catch blocks, custom exceptions, checked exceptions, and finally blocks.
